# Registro de publicación para evaluación

Esta copia pública es un repositorio nuevo e independiente. Se ha preparado seleccionando los archivos de NF3 y empezando desde un historial Git nuevo. No se ha importado la historia completa del fork privado.

**Archivos incluidos:** interfaz, API, módulos de datos/IA/Grad-CAM/PDF, lanzador, dependencias, pruebas y workflows, diagramas SVG sin identificadores personales, manifiesto NIH y resultados tabulares, documentación del alcance.

**Excluidos deliberadamente:** documentos históricos de Fase 0 y NF2 con posibles datos personales, memoria académica con nombres del equipo, datos de radiografías originales, pesos descargados, entornos locales, bases de datos, tokens y credenciales, capturas no necesarias y registros antiguos privados.

**Control de licencias:** las bibliotecas y pesos de terceros conservan sus atribuciones y condiciones originales; ningún checkpoint está contenido aquí. La visibilidad pública permite revisar el proyecto, pero no concede por sí sola una licencia general de redistribución de todas las contribuciones del equipo.

**Privacidad:** revisar antes de introducir nuevos archivos o secretos. No subir `data/`, `.tria-local/`, `.venv*`, imágenes con metadatos clínicos ni exportaciones de informes con información personal.

**Limitación de la publicación:** un repositorio GitHub público permite ver el código y las pruebas, pero no aloja automáticamente el servidor local FastAPI. Para usar el programa se ejecuta localmente; no se expone a Internet.
